# 开发规划

本目录保存项目现状分析、能力差距与阶段目标；具体实现方案放在 `docs/design/`，实施过程与验证记录放在 `docs/log/`。

| 编号 | 文档 | 状态 |
|---|---|---|
| 01 | [项目现状分析与后续开发规划](01-project-analysis-and-roadmap.md) | 方向草案，待逐阶段细化 |

规划中的版本号和优先级用于讨论开发顺序，不代表已承诺的发布范围或日期。后续细化时，应先核对实际代码和依赖版本，再确定设计与验收条件。
