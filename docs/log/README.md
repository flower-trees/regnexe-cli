# 开发日志

从 2026-11 起，开发日志按月建目录、按天记录：

```text
docs/log/
├── README.md
└── YYYY-MM/
    └── YYYY-MM-DD.md
```

- 每月一个目录，每天一个 Markdown 文件；同一天的后续工作追加到原文件。
- 每项工作记录背景、实际改动、验证结果、限制与后续事项。
- 未执行的验证明确标注，不把计划或推测写成已完成事实。
- 日志使用实际工作日期；Git 提交说明统一使用英文。
- 已有历史日志保留原路径，避免打断历史引用。
