# 2026-11-07 开发日志

## 1. 应用内拖选、高亮与松开自动复制

用户确认沿用 Claude Code 全屏路线，要求实现一版同时支持固定输入、历史鼠标滚动和普通拖选复制的交互。此次在之前未提交的原生选择优化上继续开发，没有修改已推送的 452793f。

- 默认 ui.mouse 改为 true，拖动历史文字建立反色选区，松开自动复制，普通单击不覆盖剪贴板；滚轮、滚动条和键盘翻页继续可用。/mouse off 保留原生选择兼容模式。输入草稿不丢失，Esc 中断、Ctrl+C 退出的语义保持不变；Alt+C 可重试复制。
- TranscriptViewport 以逻辑行 ID 和 UTF-16 偏移保存选区，用显示列宽与字素边界映射中文、emoji 和组合字符。自动折行不加入复制文本，硬换行与空行保留；ANSI、边框、滚动条和补齐空格不复制。后台输出保留选区和回看位置，缩放重新折行不改变原文端点，淘汰已选文本时清除选区。
- 加入 SGR 鼠标报告及宽坐标解析，复用 JLine 读取器，兼容原 X10 报告；关闭鼠标模式和退出时关闭协议。
- ClipboardSupport 在独立线程中执行复制，本地 macOS 使用 pbcopy，Linux 和 Windows/WSL 使用对应工具。原生工具以固定参数启动、选中文本只通过 UTF-8 stdin 传递；超时覆盖 stdin 写入及进程等待，关闭时终止相关进程。SSH 或本地失败尝试 OSC 52，明确提示终端可能需要授权，不将发送成功等同于剪贴板已更新。限制单次复制 1 MiB，异步结果按选区代次更新状态反馈。

新增测试覆盖逻辑选区、反向拖动、中文宽字符、emoji、组合字符、软折行与硬换行、后台追加与历史淘汰，以及剪贴板字面 stdin、超时、OSC 52 和 SGR 解析。真实 PTY 使用 PATH 中的假剪贴板工具和临时文件，验证高亮与实际复制字节，不修改真实系统剪贴板。双击选词、三击选行和停留边缘持续自动滚动留待后续。

验证结果：mvn -q package 的 85 项 Java 测试全部通过；本地模拟模型 + 真实 PTY 的 11 项回归全部通过，新增用例验证中文/组合字符/emoji 高亮、跨行复制内容、单击不复制、输入草稿保留、缩放后选区保留、Alt+C 重试、原生失败后的 OSC 52 原文，以及 Ctrl+C 退出。Python AST 与 git diff --check 通过。复制后端为临时脚本和文件，未测试或更改真实系统剪贴板；未调用外部模型或 Opik。JAR 已更新，重启后可试用；改动尚未提交或 push。
