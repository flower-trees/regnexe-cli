# 2026-11-12

指定 Skill 已接入普通任务的计划、执行、反思、持久化、取消和恢复链路，减少独立执行逻辑；纯指令 Skill 不再因为没有工具调用就被直接视为未执行。相关说明见 [Skill 调用](../../design/03-skill-slash-invocation.md)。

增加可选执行预算：单轮迭代硬上限、任务累计模型调用上限及停止原因记录，恢复时继续累计。它限制调用次数，不是计费 Token 硬上限。Agent 本地测试和 CLI 回归通过，不能据此认定业务准确率提高。

已知待讨论项：指定 Skill 对额外声明工具的限制与 Auto 不一致；预算对象同时影响重试及临近上限提示。此次整理不修改这两处行为。
