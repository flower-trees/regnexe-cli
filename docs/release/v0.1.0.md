# Regnexe CLI 0.1.0 发布准备

## 功能范围

- 基于 regnexe-agent 的终端交互助手：模型规划、文件与 Shell 工具、执行事件渲染。
- SQLite 会话历史和任务账本，`/resume` 继续未完成任务。
- Skill 直接调用、插件安装与启用、MCP 服务接入。
- 可选 Opik 追踪，通过 spanId / parentSpanId 关联调用；默认关闭。
- Java 17，可执行 JAR，macOS / Linux Bash 安装脚本。

## 本轮发布准备

- 依赖从 `regnexe-agent 0.1.3-SNAPSHOT` 切换为正式版 `0.1.3`。
- 修复会话历史迁移误归属：使用事务和一次性标记，不再每次启动执行哈希替换；保留数字会话名、哈希碰撞和目标记录冲突，限制为 CLI 的 app/user 0/0 数据。
- 新增迁移、会话隔离、任务状态持久化和真实消息子类型恢复测试。
- `rex --version` 从 Maven 生成的构建信息读取，不再在 Java 中重复维护版本号。
- 整理重复的 Spring Boot repackage，保留一次可执行打包。
- 安装脚本支持从任意工作目录调用，也支持解压后的发布目录。
- 新增中英文 README、配置说明、验证指南和生成发布压缩包/校验值的脚本。

## 升级说明

退出所有 rex 进程并备份整个 `~/.rex` 后再启动新版本。保留的歧义记录需在备份副本中人工核实，既有错误归属无法靠迁移自动还原。不支持旧版本回写同一个已升级数据库。详情见 [验证指南](../guide/release-validation.md)。
