# Regnexe CLI 0.1.0 Release Preparation

## Scope

- Interactive terminal assistant built on regnexe-agent, with model planning, file and shell tools, and execution rendering.
- SQLite conversation history and task ledger, with `/resume` for unfinished tasks.
- Direct Skills, plugin installation/enabled state, and MCP integration.
- Optional Opik tracing using spanId / parentSpanId; disabled by default.
- Java 17 executable JAR and a Bash installer for macOS / Linux.

## Preparation Changes

- Replace `regnexe-agent 0.1.3-SNAPSHOT` with stable `0.1.3`.
- Fix history misassignment during migration: migrate once in a transaction, preserving numeric-name ambiguity, hash collisions, and conflicting destination records. Restrict migration to CLI app/user 0/0 data.
- Add migration, conversation isolation, persisted task state, and message subtype restoration tests.
- Read `rex --version` from Maven-generated build metadata instead of duplicating the version in Java.
- Remove duplicate Spring Boot repackage execution.
- Support installation from any working directory and from an extracted release archive.
- Add bilingual READMEs, configuration/validation guides, and a local archive/checksum packaging script.

## Upgrade

Exit all rex processes and back up the entire `~/.rex` directory before opening it with this build. Inspect a backup copy to recover ambiguous records; already misassigned history cannot be automatically reconstructed. Do not allow older builds to write into the upgraded database. See the [validation guide](../guide/release-validation.md).
