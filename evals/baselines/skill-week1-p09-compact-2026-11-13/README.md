# P09 反思输入优化：本地验证

只对显式配置 `offline_text_review` 的独立离线文本任务启用；调用方负责提供完整摘要和验收条件。当前仅评测配置启用，普通 CLI 任务不启用。事实源完整保留一次，候选文本按字段保留一次，在原句前插入断言编号；不调用额外 LLM 压缩。

首轮、无会话历史、执行成功、无工具执行记录，且输出严格解析为非空平面字符串 JSON 对象时才压缩。其他情况保留原 Goal/Plan/输出/工具记录路径。重复键、尾随 JSON、嵌套/数值字段及编号标记冲突也回退。

验收条件与原用例保持两字段、事实保留、清除内部备注和“官网”、按信息量分段的要求；不会把答案参考稿传给模型。新输入见 [prompt.txt](prompt.txt)。事实和原段落标点未丢弃，原失败答案13条断言编号不变。

实际事件渲染长度从5669降至2500字符，减少55.9%；这是包含消息包装的字符比较，不是 token 计费结果。76项 Agent 本地测试、87项 CLI 测试和1项模拟执行链测试通过。模拟回放只调用一次本地固定响应 Reflector，缺少核验协议的历史 FINISH 仍被拒绝。

本轮真实模型调用为0；没有证明语义准确率提升或真实 token 降幅。原 P09 真实测评保留在相邻目录。UNCERTAIN 分类和覆盖原 reason/hint 的策略没有修改，后续校准单独处理。冻结 baseline 是本次模拟回放版本；随后只增加了历史断言与回退测试，没有修改生产实现或配置。
